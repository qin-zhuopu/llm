# Sight Machine — Agentic 制造平台

> 来源: https://www.sightmachine.com/
> 抓取日期: 2026-08-27

Sight Machine 是 AI 原生的制造分析公司。2026 年推出 **Agentic Manufacturing Platform（Agentic 制造平台）**，声称"理解你的工厂并每一轮次都改进它"。由 NVIDIA（NVentures）投资。

## 定位

- **模型系统型**：工业语义模型 + Agentic 编排层（按需构建行业专用 ML 工具）+ MCP 服务器暴露给企业 LLM Agent。
- 核心主张："通用 AI 工具无法读懂原始工业数据"，需要语义模型 + 动态生产 + 企业 Agent 才能实现自主运营。

## 三大支柱

1. **Semantic Model（语义模型）**：连接所有 OT/IT 系统（控制器、历史库、MES、ERP），将物理工厂映射为一个结构化模型，把原始信号转成生产事件和 KPI，供 Agent 行动。"工业数据，Agent 就绪。"
2. **Dynamic Production（动态生产）**：Agent 持续调查生产、构建并使用行业专用 ML 工具；经验证的发现变成运营团队可执行的实时建议。
3. **Enterprise Agents（企业 Agent）**：将制造智能作为 **MCP（Model Context Protocol）服务器**发布，使企业内任意 Agent 可集成车间 AI；发现推送到 Teams、运行 NVIDIA Omniverse 仿真、连接 Databricks ML 模型。

## 技术特点

- OT/IT 语义数据模型（控制器、历史库、MES、ERP）。
- Agentic 编排层，实时构建行业专用 ML 工具。
- 通过 MCP 服务器暴露智能，与企业 LLM Agent 互操作。
- 集成：Microsoft Teams、NVIDIA Omniverse（数字孪生仿真）、Databricks。

## 成效数据（公司自报）

- 产出提升 10%+；数天完成部署；服务 20+ 行业；7x24 Agent 在线。
