# 工业制造 (Manufacturing)

> 工业自动化、预测性维护、质量检测、PLC编程等场景的AI大模型应用

## 概述

工业制造领域的AI大模型应用正在从概念验证走向规模落地。从PLC编程辅助到工程文档理解，从预测性维护到供应链优化，AI正在提升制造业的智能化水平。头部工业软件公司和云服务商是主要推动力。
