# 会计审计 (Accounting & Audit)

> 财务审计、税务合规、报表分析等场景的AI大模型应用

## 概述

会计审计领域的AI大模型应用主要由四大会计师事务所和专业软件厂商推动。从税务合规到审计自动化，从财务分析到风险评估，AI正在提升会计审计工作的效率和质量。

## 市场规模

会计审计AI市场因合规要求提升和审计工作量增长而持续扩大。四大事务所的AI投入推动行业变革。
