# 汽车出行 (Automotive)

> 自动驾驶决策、座舱交互、交通规划等场景的AI大模型应用

## 概述

汽车行业正在经历智能化变革，大模型在自动驾驶认知决策、座舱多模态交互和车载AI助手等方面展现出巨大潜力。中国新能源车企和全球自动驾驶公司是该领域最活跃的参与者。
