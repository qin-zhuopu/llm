# 能源 (Energy)

> 电力调度、油气勘探、碳排管理、新能源预测等场景的AI大模型应用

## 概述

能源行业的AI大模型应用覆盖了从传统油气到新能源的全产业链。电力负荷预测、设备预测维护、油气勘探优化是主要应用方向。中国和全球能源巨头均在加速AI部署。

## 市场规模

能源AI市场规模巨大，电力和油气是最大的两个细分领域。碳中和目标推动新能源AI需求快速增长。
