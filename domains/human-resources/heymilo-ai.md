# HeyMilo

HeyMilo 是面向高量级招聘（high-volume hiring）的 AI 招聘官（AI Recruiter），用结构化的 AI 语音、视频、SMS 和表单对每一位投递者进行筛选与面试，7×24 小时运行、支持 20+ 语言，在不牺牲质量与准确性的前提下自动化漏斗筛选与分流。

## 能力

- 双向对话式面试（Two-way Conversational Interviews）：表单筛选、SMS 面试、语音面试、视频面试多渠道；示例中语音智能体可按候选人请求切换到西班牙语。
- 打分：Fit score 及分项拆解（经验、技能、沟通、可用性、可靠性），并给出打分理由；信任信号包括身份验证、无作弊标记、简历匹配。人工在环（human in the loop），排序短名单同步到 ATS。
- 反作弊：主动监考层 + AI 分类器，输出表示作弊可能性的 trust score。
- 客观评分：题目可配置客观评价标准；每个分数附带详细理由；第三方偏见审计（伦理 AI）。

## 商业成效（自报）

1.4M+ 候选人被筛选；筛选成本降低约 90%（TRG）；每周为招聘官释放 80+ 小时（Inergroup）；47 个门店/地点运行语音筛选（Neo Financial）；候选人平均满意度 4.6/5。热门岗位：仓库工、注册护士、销售代表、CDL 司机、客服。

## 集成

ATS 集成：Greenhouse、Bullhorn、Avionté、Ashby、Workday、SmartRecruiters、JobDiva；结构化分数、PDF 报告、转录与录音回写候选人记录；提供 MCP server 查询招聘数据。定位为工作流应用型（对话式语音/文本 Agent + 评分模型）。
