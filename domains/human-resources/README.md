# 人力资源 (Human Resources)

> 简历筛选、人岗匹配、培训内容生成等场景的AI大模型应用

## 概述

人力资源领域的AI大模型应用主要集中在招聘和人才管理环节。从简历筛选到候选人匹配，从面试评估到职业路径规划，AI正在提升HR工作的效率和精准度。

## 模型列表

| 模型 | 公司 | 说明 |
|------|------|------|
| [LinkedIn Hiring AI](./linkedin-hiring-ai.md) | LinkedIn(Microsoft) | 简历筛选/候选人匹配/招聘文案 |
| [Eightfold AI](./eightfold-ai.md) | Eightfold | 人才智能/技能匹配/职业路径 |
| [北森AI](./beisen-ai.md) | 北森 | HR SaaS+AI/简历解析/面试评估 |

## 市场规模

HR AI市场因招聘效率提升和人才竞争加剧而持续增长。AI招聘工具的渗透率正在快速提升。
