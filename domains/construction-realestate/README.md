# 建筑地产 (Construction & Real Estate)

> 建筑设计、BIM协同、造价估算、合规审查等场景的AI大模型应用

## 概述

建筑地产行业的AI大模型应用主要集中在建筑设计辅助、BIM协同和造价估算等方面。从方案设计到合规审查，AI正在提升建筑行业的设计效率和项目管理水平。

## 市场规模

建筑AI市场因BIM数字化和绿色建筑需求而增长，设计辅助和造价管理是最先落地的场景。
