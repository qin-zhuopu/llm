# 电商零售 (Retail & E-commerce)

> 客服、选品、商品文案、供应链、推荐等场景的AI大模型应用

## 概述

电商零售领域的AI大模型应用覆盖了从商家运营到消费者体验的完整链条。智能客服、商品文案生成、营销优化和购物助手是当前最活跃的应用场景。中美两大电商市场的头部平台都在加速AI能力建设。

## 市场规模

电商AI市场规模庞大，仅智能客服一项就是百亿级市场。随着大模型能力提升，商品文案生成和个性化推荐正在快速增长。
