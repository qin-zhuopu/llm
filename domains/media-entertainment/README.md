# 媒体娱乐 (Media & Entertainment)

> 内容生产、剧本创作、游戏NPC、新闻摘要等场景的AI大模型应用

## 概述

媒体娱乐行业是AI大模型应用最为多样化的领域之一。从营销文案到游戏NPC对话，从网络文学创作到视频内容生成，AI正在改变内容产业的生产方式。
