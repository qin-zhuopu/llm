# 政务 (Government)

> 政务问答、公文写作、舆情分析、城市大脑等场景的AI大模型应用

## 概述

政务领域的AI大模型应用主要集中在政务问答、公文写作和舆情分析等方面。中国的科技巨头均推出了面向政务场景的大模型解决方案，助力政府数字化转型。
