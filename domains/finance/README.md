# 金融 (Finance)

> 银行、证券、保险、投研、风控、合规等场景的AI大模型应用

## 概述

金融是垂直领域大模型应用成熟度最高的行业之一。各大金融机构和金融科技公司纷纷推出专属大模型，覆盖投研分析、风险控制、智能客服、合规审查等核心业务场景。金融数据的专业性和合规要求使得垂直模型相比通用模型具有显著优势。

## 市场规模

金融AI市场是垂直领域中规模最大的细分市场之一，预计2030年将达到数百亿美元规模。头部投行和金融科技公司持续加大AI投入，推动行业智能化转型。
