# Cursor (Tab / Fusion) — AI 编程 Agent 与 IDE

> 来源: https://cursor.com
> 抓取日期: 2026-08-26

Cursor 是面向软件开发的 AI 编程 Agent 和 AI-native IDE，采用"自研专用模型 + 多前沿模型 + IDE 工作流"的混合架构。

## 核心能力

- **自主运行、并行工作**：Agent 使用自己的计算机端到端构建、测试和演示功能供审查
- **无处不在**：在终端运行、在 Slack 协作、在 GitHub 审查 PR
- **自动化重复工作**：设置常驻 Agent 按计划或触发器构建、维护和修复软件

## 模型策略（混合架构）

- **自研 Tab/Fusion 模型**：稀疏模型，在数十亿 token 的编辑预测任务上训练，负责低延迟、强交互的补全与跳转
- **多前沿模型**：复杂 Agent 任务调用 OpenAI、Anthropic、Gemini 等更强通用模型
- **Auto 路由**：根据可靠性自动切换模型

## 定位（据行业报告）

Cursor 的护城河更接近"自研高频专用模型 + IDE 工作流 + 代码库上下文 + 开发者行为数据 + 多模型路由"，而非一个统一的编程基础模型。属于混合型（Hybrid）——自研 Tab 模型是关键交互专用模型（真正训练的垂类模型），但复杂推理依赖通用模型。代码运行结果客观、开发者行为数据高频，形成产品数据闭环。主要风险是基础模型竞争、毛利与平台依赖。
