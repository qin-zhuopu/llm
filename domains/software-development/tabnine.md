# Tabnine — 强调企业控制的 AI 代码助手

> 来源: https://www.tabnine.com ，https://en.wikipedia.org/wiki/Tabnine
> 抓取日期: 2026-08-27

Tabnine 是最早的 AI 代码补全工具之一，定位"更聪明的 AI 编码 Agent + 完整企业控制"。属于**模型系统型**：自研/托管面向代码的 AI 模型 + 企业上下文引擎，强调私有部署、合规与"仅在授权代码上训练"的可控性。

## 公司沿革
- 前身 Codota，2013 年由 Dror Weiss（CEO）与 Eran Yahav（CTO）在以色列特拉维夫创立，基于 Technion 十余年学术研究。
- 2017-06 $2M 种子；2018-06 推出首个 Java IDE 的 AI 代码补全。
- 2019 收购 Tabnine（用当时新兴的 LLM 技术为多语言、5 个 IDE 提供生成式代码）。
- 2020-04 Series A $12M（Khosla Ventures 领投）。
- 2021-05-26 Codota 更名 Tabnine，发布公司首个基于 LLM 的 AI 编码助手。
- 2022-04 用户超 100 万；2022-06 融资 $15.5M（Qualcomm Ventures 联合领投），推出可预测整行/片段的模型。
- 2023-06 推出 AI 聊天 Agent（自然语言生成代码、解释代码、生成测试与文档、提出修复）。
- 2023-11 Series B $25M 用于扩张。
- 截至 2023-11：百万开发者使用，VS Code 与 JetBrains 上安装量达 1000 万。

## 企业上下文引擎
Tabnine 的 Enterprise Context Engine 学习组织特有的架构、框架与编码规范，适配混合技术栈与遗留系统，确保建议契合安全、合规与性能要求，把 AI 变成"受治理、上下文感知"的团队成员。强调总企业控制（含私有部署、可用不含未授权代码的模型）。

## 定位
模型系统型：自研/托管专用代码模型 + 企业上下文引擎，差异化在"企业可控 + 合规 + 私有部署"，而非追求最大规模的通用模型。
