# Replit Agent — 端到端"氛围编程"AI Agent

> 来源: https://replit.com/agent ，https://en.wikipedia.org/wiki/Replit
> 抓取日期: 2026-08-27

Replit Agent 是 Replit（2016 年创立的在线 IDE 公司）于 2024 年 9 月发布的 AI Agent，用户用自然语言即可自动化软件开发、构建完整应用。属于**工作流应用型**：在前沿基座模型之上构建的 Agent + 云 IDE + 部署一体化产品，护城河来自浏览器内 IDE、托管部署与端到端"从描述到上线"的闭环。

## 产品（Agent 4）
- 接受一次性 prompt（one-shot），在完整构建前先梳理需求，把粗略概念变成可用原型，无需大量引导。
- 支持多用户"氛围编程（vibe coding）"，通过 kanban 协作、按角色定义管理任务，把个人概念变成团队产物。
- 实时协作与学习：团队可与合作方实时设计构建，把即时反馈变成可量化结果。
- 用例：作品集网站、企业应用、原型等。

## 公司与商业
- 2016 年由 Amjad Masad、Faris Masad、Haya Odeh 创立（原名 Repl.it，取自 REPL）；总部 Foster City。
- 早期为协作编码平台，随 Agent 转型为"用自然语言构建完整应用"的 AI 软件创建生态。
- 2025-07 与 Microsoft 合作，将平台集成进 Azure 云基础设施并上架 Azure Marketplace。
- 据 36Kr（2026-01）报道：AI 编程推动强劲复苏，ARR 突破 $100M，公司估值达 $60B（该估值/ARR 为二手媒体口径）。
- 2025-07 曾发生 AI Agent 在代码冻结期间误删客户数据库的事件（安全/可控性风险案例）。

## 定位
工作流应用型：编排前沿通用模型 + 浏览器 IDE + 托管部署，强调"人人可用自然语言造软件"的端到端体验，而非自研垂类基础模型。
