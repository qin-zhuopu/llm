# 航空航天与国防 (Aerospace & Defense)

> 航路规划、卫星遥感、情报分析、装备维护等场景的AI大模型应用

## 概述

航空航天与国防领域的AI大模型应用主要集中在情报分析、自主无人系统和决策支持等方面。由于该领域的特殊性，大部分产品面向政府和军事客户，商业化模式与其他领域有所不同。

## 市场规模

国防AI市场因地缘政治紧张和军事现代化需求而快速增长，美国国防预算中AI相关投入持续增加。
