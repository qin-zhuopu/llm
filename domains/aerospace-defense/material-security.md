# Material Security — 工作区安全 AI（Google Workspace / Microsoft 365）

> 来源: https://www.materialsecurity.com
> 抓取日期: 2026-08-26

Material Security 是面向 Google Workspace 和 Microsoft 365 的工作区安全平台，主张"工作区安全是 AI 安全的基石"。阻止邮件攻击、控制 agent/app 访问、保护敏感数据。

## 覆盖工作区攻击链

1. 邮件入侵（凭证钓鱼/社工/BEC）
2. 账户接管（转发规则、OAuth 授权、遗留认证）
3. 数据渗出（批量导出、敏感数据搜索）
4. 横向移动（密码重置、验证码、生产密钥）

## 产品（单一平台）

- 入站邮件安全（捕获 Google/Microsoft/SEG 漏掉的攻击）
- **OAuth Remediation Agent**：保护第三方 app 和 AI agent，显示实时活动日志，可即时撤销
- 文件安全（发现 Drive 过度共享的 PHI/PII，批量修复）
- 账户接管遏制（消息级访问控制）
- API 分钟级部署

## 关键数据

- AI 后钓鱼增长 13x、平均 241 天识别泄露、平均邮箱 7 年敏感数据、39% 泄露涉及凭证滥用

## 定位

网络安全（工作区）垂类 AI，模型系统型。差异化在于"控制 AI agent 访问"——AI 时代的新安全面。客户 Gusto、Amplitude 等。
