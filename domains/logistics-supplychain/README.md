# 物流供应链 (Logistics & Supply Chain)

> 路线优化、仓储管理、需求预测、调度等场景的AI大模型应用

## 概述

物流供应链是AI大模型应用落地较快的领域之一。从路线优化到仓储管理，从需求预测到智能调度，AI正在帮助物流企业降本增效。中国头部物流企业和全球供应链科技公司均在积极布局。

## 市场规模

物流AI市场因电商增长和供应链复杂度提升而持续扩大，智能调度和路线优化是最大的应用场景。
