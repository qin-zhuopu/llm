# 气象环保 (Climate & Environment)

> 天气预报、气候建模、环境监测、灾害预警等场景的AI大模型应用

## 概述

气象环保领域是AI大模型科研应用的典型代表。多个AI天气预报模型已在精度上超越传统数值方法，且推理速度快数个数量级。华为、DeepMind等机构在该领域取得了突破性进展。

## 市场规模

气象AI市场因极端天气频发和精准预报需求增长而快速扩大。AI气象模型正在从科研走向商业化应用。
