# 材料科学 (Materials Science)

> 新材料发现、材料性能预测、配方优化等场景的AI大模型应用

## 概述

材料科学是AI大模型应用最具科研价值的领域之一。从新材料发现到性能预测，从配方优化到高通量筛选，AI正在加速材料科学的研究进程。DeepMind的GNoME等模型已证明AI在材料发现方面的巨大潜力。

## 模型列表

| 模型 | 公司 | 说明 |
|------|------|------|
| [GNoME](./deepmind-gnome.md) | Google DeepMind | 220万新晶体/38万稳定材料 |
| [Citrine](./citrine.md) | Citrine Informatics | 材料性能预测/配方优化 |
| [微矿智云](./weikuang-ai.md) | 中科院合作 | 矿物材料性能预测 |

## 市场规模

材料AI市场因新能源、半导体等行业对新材料的需求而快速增长。AI驱动的材料发现正在成为材料科学的新范式。
