# 药物研发 (Pharma & Biotech)

> 靶点发现、分子生成、临床试验优化等场景的AI大模型应用

## 概述

药物研发是AI大模型应用最具变革潜力的领域之一。从靶点发现到分子设计，从临床试验优化到药物重定位，AI正在显著缩短新药研发周期。多家公司已有AI辅助发现的药物进入临床试验阶段。
