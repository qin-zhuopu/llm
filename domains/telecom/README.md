# 电信 (Telecom)

> 网络运维、故障预测、客服、资源调度等场景的AI大模型应用

## 概述

电信行业的AI大模型应用主要集中在网络运维自动化、智能客服和网络优化等方面。中国三大运营商均已发布自研大模型，全球电信设备商也在积极布局AI能力。

| 模型 | 公司 | 说明 |
|------|------|------|
| [中国移动九天](./chinamobile-jiutian.md) | 中国移动 | 网络运维/智能客服 |
| [中国电信星河](./chinatelecom-xinghe.md) | 中国电信 | 政企服务/网络智能运营 |
| [Ericsson AI](./ericsson-ai.md) | 爱立信 | 网络运维自动化/故障定位 |

## 市场规模

电信AI市场因网络复杂度提升和运维成本压力而快速增长，5G网络的大规模部署进一步推动了AI需求。
