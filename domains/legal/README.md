# 法律 (Legal)

> 合同审查、法律研究、诉讼支持、合规等场景的AI大模型应用

## 概述

法律行业是AI大模型商业化最成功的垂直领域之一。从合同审查到法律研究，从诉讼支持到合规管理，AI正在帮助法律从业者显著提升工作效率。头部法律AI公司已获得大量融资并服务数千家法律机构。

## 市场规模

法律AI市场增长迅速，Harvey AI等公司估值已超过数十亿美元。法律服务的高度文本化和标准化使其成为大模型应用的理想场景。
