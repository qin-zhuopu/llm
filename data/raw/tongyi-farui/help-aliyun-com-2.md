<h2 id="模型服务">模型服务 <span id="922b9a6d12rkv"></span> <span id="41e93c6107f6y"></span></h2>
<h3 id="开箱即用的模型">开箱即用的模型 <span id="fe7105269ezlc"></span> <span id="d6a75263b5lrw"></span></h3>
<p>百炼提供开箱即用的模型服务，无需自行部署或运维，直接调用自研千问（Qwen）全系列模型，以及 DeepSeek、Kimi、GLM 等第三方大模型。详情请参见<a href="/zh/model-studio/models">选择模型</a>。</p>
<ul>
<li>
<p><strong>千问（Qwen）系列旗舰模型</strong>：</p>
<ul>
<li>
<p>千问 Max：Qwen 系列效果最好的模型，适合处理复杂、多步骤任务。</p>
<blockquote>
<p>最新的 qwen3.8-max 推理能力全面超越前代，推荐选用。</p>
</blockquote>
</li>
<li>
<p>千问 Plus：效果、速度和成本均衡，是多数场景的<strong>推荐选择</strong>。</p>
</li>
<li>
<p>千问 Flash：高性价比、低延迟，适合需要快速响应的简单任务。</p>
</li>
</ul>
</li>
<li>
<p><strong>多模态覆盖</strong>：涵盖文本生成、视觉理解、图像生成、视频生成、语音识别与合成、嵌入向量等多种能力。</p>
</li>
<li>
<p><strong>细分领域模型</strong>：提供长文本处理、翻译、数据挖掘、法律、意图理解、角色扮演、深入研究等多种领域模型。</p>
</li>
</ul>
<h3 id="模型调优-部署和评测">模型调优、部署和评测 <span id="c988c988a4uub"></span> <span id="d1d1d121d4ju8"></span></h3>
<ul>
<li><a href="/zh/model-studio/model-training-overview">模型调优</a>：支持有监督微调（SFT）、继续预训练（CPT）和直接偏好优化（DPO），满足特定业务需求。</li>
<li><a href="/zh/model-studio/model-deployment-introduction">模型部署</a>：将预置模型或调优后的自定义模型部署为资源专享的推理服务，满足高并发、低延迟等性能要求。支持按时长、包月、按 Token 量等多种计费方式。</li>
<li><a href="/zh/model-studio/model-evaluation-overview">模型评测</a>：提供人工评测、自动评测和基线评测，支持快速对比不同模型表现，验证调优效果，提前发现潜在调用风险。</li>
</ul>
<h2 id="应用构建">应用构建 <span id="9883028424aej"></span> <span id="01c09c08a2a73"></span></h2>
<ul>
<li><strong>应用类型：</strong>提供可视化和高代码两种开发模式。可视化模式可快速创建<a href="/zh/model-studio/single-agent-application">智能体应用（Agent 1.0）</a>和<a href="/zh/model-studio/workflow-application">工作流应用</a>；<a href="/zh/model-studio/rich-code-application">高代码应用</a>则支持将 Python 项目部署为后端服务，具备自动化运维、可观测、日志服务等能力。</li>
<li><strong>功能拓展：</strong>通过<a href="/zh/model-studio/rag-knowledge-base">知识库（RAG）</a>接入私有数据和专业领域知识；通过<a href="/zh/model-studio/plug-in-overview">插件</a>和<a href="/zh/model-studio/mcp-introduction">模型上下文协议（MCP）</a>调用外部服务。</li>
<li><strong>分享与发布：</strong>支持将应用发布至网页、钉钉机器人、微信公众号及音视频互动智能体等多种平台，详见<a href="/zh/model-studio/share-an-application">应用分享</a>。</li>
</ul>

<h3 id="模型推理与知识库的计费区分">模型推理与知识库的计费区分 <span id="billing-distinction-title"></span> <span id="billing-distinction"></span></h3>
<p>百炼平台各功能按不同维度独立计费：</p>
<ul>
<li><strong>模型推理</strong>（如 deepseek-v3.2-exp 等大语言模型）：按文本生成 Token 用量计费，可使用 AI 通用节省计划抵扣。</li>

</ul>
<p>两者是百炼平台的不同功能，计费相互独立。</p>
