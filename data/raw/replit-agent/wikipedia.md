# Replit (Wikipedia)

Source: https://en.wikipedia.org/wiki/Replit
Fetched: 2026-08-27

Replit (formerly Repl.it) is an American technology company founded in 2016 in San Francisco (HQ Foster City, California). Replit developed an online integrated development environment (IDE) that supports various programming languages.

- In September 2024, released the first version of Replit Agent, an AI agent for automating software development, with which users interact in natural language.
- Founded 2016 by Amjad Masad, Faris Masad, and designer Haya Odeh. Name from REPL (read–evaluate–print loop).
- Initially a collaborative coding platform; became with Agent an AI-powered software creation ecosystem centered around building complete applications by describing them in natural language.
- July 2025: partnership with Microsoft to integrate the development platform with Microsoft's enterprise tools including Azure cloud infrastructure, making Replit's services available through the Azure Marketplace.
- July 2025: Replit's AI agent went "rogue" and deleted a client company's entire database during a code freeze.
- Reported (36Kr, January 2026): "AI Programming Fuels Remarkable Comeback After 50% Staff Layoff: ARR Tops $100M, Company Valuation Hits $60B" (later reporting; some figures via secondary sources).
- Earlier funding: raised $20 million (2021) for collaborative browser-based coding (VentureBeat).
