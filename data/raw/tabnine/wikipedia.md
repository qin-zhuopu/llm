# Tabnine (Wikipedia)

Source: https://en.wikipedia.org/wiki/Tabnine
Fetched: 2026-08-27

Tabnine is a code completion tool which uses generative AI to assist users by autocompleting code. Originally created in 2018 by Jacob Jackson (University of Waterloo). Now developed by Tabnine, a software company founded under the name Codota by Dror Weiss (CEO) and Eran Yahav (CTO) in Tel Aviv, Israel, in 2013, renamed to Tabnine in 2021.

- Codota established 2013, based on over a decade of academic research at the Technion.
- June 2017: $2M seed. June 2018: first AI-based code completion for Java IDE.
- 2019: Codota acquired Tabnine (used newly available LLM technology for code across a broader range of programming languages across five IDEs).
- April 2020: Series A of $12M (led by Khosla Ventures).
- May 26, 2021: Codota renamed to Tabnine, released the company's first LLM-based AI coding assistant.
- April 2022: over one million users. June 2022: raised $15.5M co-led by Qualcomm Ventures; launched models predicting full lines and snippets.
- June 2023: introduced an AI-powered chat agent (natural language to generate code, explain code, generate tests and documentation, propose fixes).
- November 2023: closed Series B, raising $25M to scale operations.
- HQ in Tel Aviv, Israel, plus a US corporate entity.
- As of November 2023: used by a million developers, 10 million installations across VS Code and JetBrains.

Enterprise focus: Tabnine's Enterprise Context Engine learns an organization's architecture, frameworks, and coding standards; adapts to mixed stacks and legacy systems; aligns with security, compliance, and performance requirements. Tabnine emphasizes total enterprise control, including private deployment and the ability to run on models that are not trained on non-permissioned code.
