# Algolia — Wikipedia

Source: https://en.wikipedia.org/wiki/Algolia (fetched 2026-08-27)

Algolia, Inc. is a French proprietary search-as-a-service platform, headquartered in San Francisco with offices in Paris and London. Its main product is a web search platform for individual websites.

- Founded 8 October 2012 by Nicolas Dessaigne and Julien Lemoine (Paris). Originally focused on offline search on mobile phones; selected for Y Combinator Winter 2014 class.
- As of 2019, present in over 70 data centers across 16 worldwide regions. Serves roughly 18,000+ customers, handling over 1.75+ trillion searches a year.
- Funding: May 2015 $18.3M Series A (Accel Partners); 2017 $53M Series B (Accel); July 2021 $150M Series D, unicorn at $2.25B valuation.
- Acquisitions: Morphl (Jan 2021, AI/ML startup, Romania), Search.io (Sep 2022, Australian search startup).
- Data pushed from client to Algolia via a RESTful JSON API; search box added to client web pages. Provides Rest API for search, analysis, monitoring; 10 supported languages/platforms.
- Distributed Search Network (DSN) replicates data across Algolia's network to reply to queries from locations closer to the source.
- CEO Bernadette Nixon; CTO Xavier Grand. 800+ employees.
