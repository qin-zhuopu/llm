# Open Catalyst Project — GitHub (code & baseline models)

> Source: https://github.com/Open-Catalyst-Project/ocp (now fairchem)
> Fetched: 2026-08-30
> Type: github

The Open Catalyst Project code repository provides the training/evaluation framework and open-source baseline graph neural network models (CGCNN, SchNet, DimeNet++, GemNet, and later models) for the OC20/OC22 datasets. Models, datasets, and a public leaderboard are released as open resources under the project (Meta FAIR + Carnegie Mellon University). The repository has since been consolidated under Meta's `fairchem` library.

Reference recorded from the OCP official website and the OC20 paper; content of the repository documents the open-source baseline models and evaluation tasks referenced in the model YAML.
