# Material Security — Security for Google Workspace and Microsoft 365

> 来源: https://www.materialsecurity.com
> 抓取日期: 2026-08-26

工作区安全是 AI 安全的基石。Material 阻止邮件攻击、控制 agent 和 app 访问、保护 Google Workspace 和 Microsoft 365 的敏感数据。

## 工作区攻击链（覆盖多层）

1. Email compromised（凭证钓鱼/社工/BEC）
2. Account takeover（转发规则、OAuth 授权、遗留认证漏洞）
3. Data exfiltration（批量导出、敏感数据搜索）
4. Lateral movement（密码重置、验证码、生产密钥横向移动）

## 关键数据

- AI 后钓鱼增长 13x（SlashNext）
- 平均 241 天识别并遏制泄露（IBM 2025）
- 平均企业邮箱有 7 年价值的敏感数据（Material Research 2026）
- 39% 泄露涉及凭证滥用

## 产品（单一平台）

- 入站邮件安全（捕获 Google/Microsoft/SEG 漏掉的攻击）
- OAuth Remediation Agent（保护第三方 app 和 AI agent，实时活动日志）
- 文件安全（发现 Drive 中过度共享的 PHI/PII，批量修复）
- 账户接管遏制（消息级访问控制，泄露后限制爆炸半径）
- API 分钟级部署

## 定位

网络安全（工作区/邮件）垂类 AI，模型系统型。特别强调"控制 AI agent 访问"——这是 AI 时代的新安全面。客户包括 Gusto、Amplitude 等。报告未覆盖。
