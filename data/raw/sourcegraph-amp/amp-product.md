Amp is an agentic coding tool built by Sourcegraph. It is an autonomous coding agent that leverages Sourcegraph's codebase context and code intelligence (indexing all repositories, MCP-connected context gathering across internal docs, ticket details, build statuses, and code search) to make multi-file, cross-cutting changes with full codebase awareness. Amp is model-agnostic, orchestrating frontier models on top of Sourcegraph's retrieval/context engine ("agents are only as good as the context they receive").
