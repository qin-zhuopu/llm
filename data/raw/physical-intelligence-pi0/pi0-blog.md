# π0 Blog / Model Timeline

Source: https://www.physicalintelligence.company/blog/pi0 and https://physicalintelligence.company/ (fetched 2026-08-27)

Blog index of Physical Intelligence model releases:
- π0.7 (2026-04-16): a steerable model with emergent capabilities; step-change in generalization.
- Precise Manipulation with Efficient Online RL (2026-03-19): extract an RL Token from VLA models for fast online RL, improving throughput on precise tasks with few hours of data.
- VLAs with Long and Short-Term Memory (2026-03-03): Multi-Scale Embodied Memory (MEM) enables tasks longer than ten minutes.
- The Physical Intelligence Layer (2026-02-24): general-purpose physical intelligence models enable a Cambrian explosion of robotics applications.
- π*0.6 (2025-11-17): a VLA that learns from experience; trained with RL to improve success rate and throughput on real-world tasks.
- Real-Time Action Chunking with Large Models (2025-06-09).
- π0.5 (2025-04-22): extends π0 with open-world generalization.
- Open Sourcing π0 (2025-02-04): released weights and code for π0 plus π0-FAST autoregressive model.
- FAST: Efficient Robot Action Tokenization (2025-01-16): action tokenizer that trains generalist policies 5x faster.
- π0 (2024-10-31): first generalist policy; combines large-scale multi-task, multi-robot data collection with a new network architecture for dexterous generalist robot control.
